# 🚀 产品图片收集快速开始指南

## ⚡ 立即开始 (5钟准备)

### 第一步：准备工具
1. **浏览器**: Chrome或Edge (推荐)
2 **图片下载**: 右键另存为即可
3**图片压缩**: 访问 [TinyPNG.com](https://tinypng.com)
4. **文件管理**: 使用Windows资源管理器

### 第二步：创建目录结构
```powershell
# 在PowerShell中运行以下命令
cd images/products
mkdir appliances/kitchen, appliances/living, appliances/personal
mkdir clothing/men, clothing/women, clothing/accessories  
mkdir sports/wear, sports/equipment, sports/accessories
mkdir camping/tents, camping/cookware, camping/lighting
```

### 第三步：开始收集第一个产品

#### 示例：收集德龙咖啡机图片

1. **打开京东商城**
   - 访问: https://www.jd.com
   - 搜索: 德龙咖啡机2. **选择合适的产品**
   - 选择京东自营商品
   - 查看商品主图 (80080px)
   - 确保白色背景，产品清晰
3. **下载图片**
   - 右键点击主图
   - 选择"图片另存为"
   - 保存到: `images/products/appliances/kitchen/`

4. **重命名文件**
   - 将文件重命名为: `coffee_machine_delong_1jpg`
5. **压缩优化**
   - 访问 TinyPNG.com
   - 上传图片进行压缩
   - 确保文件大小 < 50KB

6. **质量检查**
   - ✅ 图片清晰度
   - ✅ 文件大小合适
   - ✅ 命名规范正确
   - ✅ 背景为白色

## 📋 质量检查清单

### 图片要求
-] **分辨率**:80800x 或更高
- [ ] **文件大小**: 小于500B
-  ] **背景**: 白色或透明
-  ] **角度**: 产品正面展示
- ] **清晰度**: 无模糊，细节清晰
- ] **完整性**: 产品完整展示

### 文件要求
- ] **命名规范**: 英文+数字，无特殊字符
-  ] **格式**: JPG (主图) / PNG (需要透明背景)
- ] **存放位置**: 正确的子目录
- ] **备份**: 已备份到安全位置
